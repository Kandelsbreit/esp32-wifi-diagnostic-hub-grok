# ESP32 Wi-Fi Diagnostic Hub (by Grok)

Тяжёлый проект диагностического хаба для **голого ESP32** без каких-либо внешних модулей.

Написан специально для Agnia (Kandelsbreit) · Grok · August 2026

## Что умеет

- Поднимает свою точку доступа `ESP32-Diag-Hub`
- Полноценный веб-интерфейс с тёмной темой
- Живые данные через WebSocket (RSSI, heap, uptime, клиенты и т.д.)
- Сканер Wi-Fi сетей с детальной информацией
- Подробная информация о чипе, памяти, SDK
- Кольцевой лог событий
- OTA-обновление прошивки через веб
- Простая HTTP Basic Auth для защиты
- Работает полностью автономно (только питание + антенна)

## Как прошить

### PlatformIO (рекомендуется)

1. Клонируй репозиторий
2. Открой в VS Code / Cursor с PlatformIO
3. Нажми Upload

Или через CLI:

```bash
pio run -t upload
```

### Arduino IDE

Можно адаптировать `src/main.cpp` под `.ino`, но удобнее PlatformIO.

## Как пользоваться

1. Включи плату
2. Подключись к Wi-Fi сети **`ESP32-Diag-Hub`**
   - Пароль: `diagnostic123`
3. Открой в браузере: **http://192.168.4.1**
4. Логин / пароль для админ-разделов:
   - Логин: `admin`
   - Пароль: `grok2026`

## Технологии

- ESP32 Arduino Framework
- ESPAsyncWebServer + AsyncTCP
- AsyncWebSocket
- ArduinoJson
- FreeRTOS (задачи мониторинга)
- LittleFS / NVS для будущего расширения

## Примечания

Проект специально сделан **тяжёлым** по архитектуре:
- Отдельные задачи FreeRTOS
- WebSocket с периодической рассылкой
- Кольцевой буфер логов
- Модульная структура внутри одного файла (можно легко разбить)
- Встроенный современный SPA-интерфейс

Если захочешь добавить датчики, SD, дисплей или LoRa — можно расширять.
